## 一句话定位

> **「会体检的行程规划师」——出发前，把这条行程的坑先踩一遍。**
> 别人帮你排行程，我们告诉你：哪一天会闭馆、哪一段来不及时、哪里绕路、哪里会超预算，并且能一键改到走得通。

首屏/分享页/README 统一用这三句：

1. **先核验，再排程**：POI 存在性 / 营业时间 / 闭馆日 / 真实通勤来自高德实时检索，不是模型记忆。
2. **先体检，再出发**：每条行程给可执行性评分（A/B/C/D）+ 风险清单，扣分规则可对账（`lib/executability.ts`）。
3. **改一次，验一次**：换一个 / 一句话改 / 一键修复后立即重体检，改了什么、风险降了多少都看得见。

## 为什么是现在：市场结论（2026-10 调研）

- **生成已红海化**：腾讯地图 2026-09 上线「计划」入口（支持复制小红书攻略链接解析成行程、邀请好友、行中共享）；
  圆周旅迹以「一键抄作业」为第一卖点；FlyAI/携程/飞猪/豆包都能生成行程。
- **「验真」被大厂做成叙事**：携程「官方权威验证开放时间/交通」、百度 V22「地图验真」、高德 2026 版
  15 维度推演（闭馆/拥堵/时间冲突）。再讲「我们接了高德」没有意义。
- **用户期待变了**：环球旅讯 2026H1 调研里「快速生成行程」只排第 4（40%），
  行中可用（翻译/导览）+ 突发预警 + 小众个性化才是付费意愿所在。
- **信任是缺口**：Expedia 委托 YouGov 调研（2026-03，5700+ 人）——68% 的人即便能用 AI 预订，
  仍更愿意在可信品牌下单。
- **AI 行程差评集中在**：通勤幻觉、营业/临时状态（缆车末班/围挡/售罄）、景区内部动线、假体验、
  太通用没个性、不可修改/不可分享、行中体验差。我们的「事实先行 + 体检 + 修复」正好打在这些上面，
  **但此前没有做成用户看得见的产品语言**。

## 明确不做

- ❌ chat-first 主入口（打不过 ChatGPT/豆包；Layla 的终局是被 Expedia 收购）
- ❌ 开放 UGC 社区（穷游/马蜂窝教训：内容库是负债，无审核团队做不好）
- ❌ 预订/比价（无供给资质，且会污染「中立核验」定位）
- ❌ 全家桶首页（飞猪/豆包的矩阵建立在已有交易供给上）
- ❌ 「更长更全的行程」当卖点

## 四条产品线与优先级

### A. 可信可见化（P0，0 外部依赖）

- A1 ✅ **可执行性评分卡**：A/B/C/D + 分数 + 一句话结论 + 可展开证据链（POI 核验 N/M、真实路段、
  避开闭馆、核验时间），分享页/结果页/工作台首屏可见（`lib/executability.ts` + `components/ExecutabilityBadge.tsx`）。
- A2 ✅ **POI 证据与未核验标记**：评分/营业时间/暂停开放已有；核验完成但无详情如实标「未核验」。
- A3 **「待确认」默认态**：预约/门票/限流/末班等核不到的信息显示「待确认 + 去官方渠道查」，不装懂。
- A4 **修复前后差异高亮**：一键修复/一句话改后高亮改动点 + 「风险从 X 降到 Y」。
- A5 **可分享的行程体检报告**：1080×1920 竖版图（城市/天数/评分/TOP 风险/二维码）。
- A6 **中立承诺页**：/about 写清「不卖排名、不隐瞒风险、不代你改行程、数据只用高德」。

### B. 内容起手（P0-P1）：补「无内容」的最便宜路径

- B1 **粘贴攻略 → 行程 v1**：用户粘贴文本（游记正文/聊天记录）→ LLM 抽取地点/偏好 → 高德核验 →
  可编辑行程。**只处理用户主动粘贴的文本，不爬站**（合规）。
- B2 ✅ **首屏精选目的地三卡** + `/new?city=&days=&prefs=` 预填（`lib/featured-destinations.ts`）；
  后续扩 20 城 × 3/4/5 天静态模板页（SEO 最小内容站）。
- B3 **收藏/愿望清单**：点位与行程级「想去」，本机存储先行。

### C. 手机行中（P1）：全行业短板 + 我们现成优势

- C1 **PWA 最小闭环**：manifest + apple-touch-icon + 分享页/`/t` 离线缓存（Next 16 内建离线或 Serwist）。
- C2 **行中提醒（站内先行）**：「下一站 XX，09:40 出发」+「我已出发/我到了」（北极星埋点也因此做实）。
- C3 **一键导航**：每站深链高德/苹果地图（餐厅电话已有）。
- C4 **预约/开门提醒**：准备包升级为出发前 48 小时清单 + 出发前 3 天天气（已有）。
- C5 **行中重规划移动优先**：求解器已有，重做移动端交互。

### D. 留存与商业（P2）

- D1 **轻身份 + 跨设备**：「我的行程」从 localStorage 迁到账号下（登录可选、不登录仍可用）。
- D2 **行前倒计时卡**：距出发 X 天 + 准备清单 + 天气/预警。
- D3 **旅程复盘**：/r 报告 → 轨迹/照片/「照着走完率」，可打印可分享。
- D4 **付费试点（顺序：增值包/按次 → 会员 → 佣金）**：单份 ¥9.9–19.9 / 年费 ¥29–49 / 增值包 ¥6–12。
- D5 **B 端白标（后期）**：文旅局/景区「可执行性核验」白标。

## 合规红线（商业化前必须解决）

高德开放平台协议 7.3 **禁止存储/缓存/下载**高德数据；当前实现把 POI 事实持久化进 Plan（分享链接长期保存），
静态地图还有 LRU 缓存。**收费/商用前需要法务确认或改为「只存引用、不落库事实原文」**。
