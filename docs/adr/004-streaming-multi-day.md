# ADR-004: ≥5 天分日流式生成

## 状态

已接受（2026-10）

## 背景

单次调用生成 5 天以上行程必爆 token（实测跑满 16 分钟仍超时）。≤4 天单次调用能扛且更快。

## 决策

按天数分流：

- ≤4 天：单次调用生成完整行程
- ≥5 天：大纲 + 逐日生成，多天并发（3 路）+ 前缀发布保序

## 理由

单次调用在 5 天以上必爆 token，拆分后每次输出都在安全区。附带收益是渐进式交付：用户逐天看到结果，不用干等 8 分钟。

## 后果

- 出场顺序不固定（第 3 天可能比第 2 天先生成完），用前缀发布解决
- 京都 5 天实测从约 900s 降到约 430s
- refine 改一天时只重算那天的 legs/通勤（未改的天沿用旧值）
