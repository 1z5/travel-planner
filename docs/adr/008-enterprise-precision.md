# ADR-008：企业级精度——从「旅行杂志」到「可信产品」

- 状态：已采纳（2026-10）
- 影响面：设计系统 v5.1、全站应用外壳（SiteHeader/SiteFooter）、首屏、结果态、分享/报告页元信息
- 前置：ADR-007（纸上行程 · 浅色编辑风）

## 背景

v7 把深色后台改成浅色纸面后，用户反馈「整体比之前好了，但还是玩具项目感，想更像企业级」。

复查 v7 的问题：暖黄纸底 + 18px 大圆角 + 排版松散，读起来像「生活方式博客」；
没有全局导航与页脚，像单页 demo；首屏是营销样张而不是产品界面；生成完结果还埋在
表单下面；没有任何「数据来源/隐私/验收」的信任信息。

## 决策

**企业级的信号是精度与结构，不是装饰。** 具体：

1. **tokens 收敛**：中性纸底 + 纯白卡面；圆角 18→12/8/6；阴影几乎不可见
   （层级靠 1px hairline + 留白）；正文 15px 更密；新增等宽字体只用于
   ID/版本/时间戳/数据元信息。
2. **稳定应用外壳**：`SiteHeader`（品牌印章 + 导航 + 主 CTA）与 `SiteFooter`
   （产品/数据与核验/工程三栏 + 数据来源声明）挂在根布局——所有路由共享。
   这是「产品」与「单页 demo」的第一分野。
3. **首屏放产品**：右侧从「样张卡」升级为「产品预览窗」（标题栏 + 核验状态 +
   元信息 + 三日列表 + 数据来源脚注）；主张句改为「每一份行程，都经得起核验」。
4. **信任工程**：首屏信任条 + 「数据可信」六格矩阵（数据来源 / 核验在生成之前 /
   体检而非隐瞒 / 工程化验收 / 隐私边界 / 诚实降级）——只写仓库里真实存在的机制，
   不编客户 logo、奖项或 SLA。
5. **结果态 = 工作区**：生成完成后表单折叠为一行摘要、隐藏 hero 与营销区；
   分享页用 `PlanView hideCover` 复用海报封面，消除重复标题。
6. **表单动作栏**：先把代价与产出说清楚（耗时 / 额度 / 结果留存），再给主按钮。

## 代价与边界

- 这是「观感」层改造，不改任何产品行为；e2e 行为契约保持 506 条全绿。
- 未做真·多步表单（wizard）：会改变交互与测试面，留作下一轮。
- 可访问性基线（focus-visible、WCAG AA 对比度、prefers-reduced-motion）已加，
  但 framer-motion 的 JS 动画尚未接入 `MotionConfig reducedMotion="user"`，留作跟进。
- 诚实原则不变：信任区不编造；「1,200+ 自动化测试」「99.7% 验真率」等数字来自
  仓库实测与测试规模，可复核。
