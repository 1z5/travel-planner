# ADR-007：纸上行程——全站从深色 Premium 改为浅色编辑风

- 状态：已采纳（2026-10）
- 影响面：全站视觉（globals.css 设计系统 v5）、首页 hero/表单、分享海报、
  旅程报告、行中页、OG 分享图

## 背景

v6 结束时产品能力完整（事实先行 / 可执行性 / 传播飞轮 / 记忆 / 流式），
但用户给出的反馈是：**「前端看起来根本不像一款优秀的产品」**。

真实截图审计（headless Chrome + CDP，桌面 1440 / 手机 390）确认了四个问题：

1. **首屏没有「画面」**：hero 只有一行字 + 抽象光晕，访客 3 秒内看不到产品长什么样；
   内容挤在 720px 窄栏，两侧大片死黑。
2. **表单像政务系统**：12+ 字段一屏平铺、无分章，主 CTA 沉底且常禁用。
3. **传播物不合格**：分享页是带警告墙的数据表格；海报封面几乎纯黑；
   真实高德地图被 CSS `invert()` 反相压成脏黑块（深色主题的补丁）。
4. **视觉系统薄弱**：字号 11–15px 混用无阶梯；层级只有「黑底 + 橙」。

## 决策

**全站改为「纸上行程」浅色编辑风**（用户明确选择「全面浅色杂志风」）：

- 暖纸底 `#f6f0e4` + 墨色 `#221d16`，强调色陶土橙 `#c2410c`
  （亮橙 `#fb923c` 在浅底读不清，必须压深）。
- 衬线标题（城市 / 天数 / 行程点名）+ 无衬线正文；正文 16px 起；字号 `clamp()` 化。
- 地图直接用高德自然色——删掉 `invert()` 滤镜。**深色主题下用反相伪造深色地图，
  本身就是失真**；浅色纸面上原色才是对的。
- 首屏加「真实示例行程样张卡」（SAMPLE_PLAN 真实 fixture，非营销插画）。
- 表单按 `01/02/03` 分章（CSS 计数器生成，不改组件结构）。
- 传播物走杂志封面语法：超大衬线城市 + 细线规格行 + 自然色地图；
  OG 图同步纸面语言。
- 体检区从「警告墙」改为编辑式体检卡（摘要 + 可展开逐条），
  **问题数始终可见**——体检而非隐瞒的红线不能被美观牺牲。

## 为什么不保留深色

- 旅行产品的传播物要能被截图、打印、收藏——浅色纸面天然适合；
- 真实地图是产品的核心视觉资产，深色主题只能靠反相「假装」深色地图；
- 深色 + 霓虹橙是「AI 工具」的视觉套路，纸面 + 衬线才是「刊物」。

## 代价与边界

- 印刷/打印样式现在与屏幕同构（不再需要强制白底覆盖），旧打印覆盖保留但多数冗余。
- 深色主题能力保留在变量层（`--bg` 等），未来若要暗色模式可另建 token 组；
  本轮不做切换（避免两套主题都要持续验收）。
- 「示意路线」（无坐标降级）从彩色正弦曲线改为水平路线条：不做伪地理装饰。
