# ATLAS 前端设计

产品页以实色表面和绿色强调组织操作。首页突出进行中的行程，无行程时提供东京步行示例，新建页先显示必填项，今日页先显示路线和导航。分享页与报告页可保留刊物式排版。

## 样式分层

`app/layout.tsx` 定义样式加载顺序。`app/styles/atlas-companion.css` 最后加载，负责当前主题与产品界面。引用现有 `--at-*` token，优先在所属分片里消除废弃规则。历史基底 `app/globals.css` 维持冻结。

| 要改什么                   | 入口                                                             |
| -------------------------- | ---------------------------------------------------------------- |
| 主题、品牌、首页与行中交互 | `atlas-companion.css`                                            |
| 工作台与核验表面           | `atlas-workspace.css` · `atlas-evidence.css` · `atlas-check.css` |
| 关于、城市模板与条款       | `atlas-marketing.css`                                            |

## 随身体验

首页封面使用浅草主题的生成版画，暖纸色页面与深绿封面形成层次。手机产品导航位于底部并避开安全区。随身交互的样式集中在 `app/styles/field-journal.css`。

「今日」使用行程中已有坐标绘制站点方位，不请求底图。坐标缺失时展示计划顺序，用户可直接选站。到达记录来自用户操作。旅行手记只写入本机，普通计划导出不含手记。

首页的「开始随走」直接进入手记。地点名称是记录停留所需的唯一输入，用户可按需附上此刻位置。实地定位点单独呈现在手记的足迹方位图中，点选即可回到对应记录。计划站点仍在「今日」按原计划显示。

## 验收

- 浅色和深色都运行视觉门禁。脚本用 CDP 设置 390px 手机视口，覆盖横向溢出、关键文字对比度、触控高度和控制台错误。
- 主操作有明确标签，键盘可操作，焦点可见。降级路径清楚说明当前数据和下一步。
- 示例卡的水乡图为生成插图，提示词为「以苏州为灵感的江南水乡，从古石桥平视运河、木船和倒影。阴天午后，白墙黑瓦与柳树，柔和的青绿色，写实旅行杂志风格，无文字或水印」。
